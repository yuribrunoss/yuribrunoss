## 🚀 Progetto in evidenza — Classificatore di feedback con IA

Un'API in produzione che classifica il feedback dei clienti e decide da
sola quando un caso necessita di una persona.

- 🧠 Classifica il sentimento (positivo / negativo / neutro) con giustificazione, usando l'**API Gemini**.
- ✍️ Suggerisce una risposta pronta da inviare al cliente.
- 🤖 Un vero **agente IA** — non una regola fissa tipo `if` — decide tramite **function calling** se un caso necessita di un follow-up umano, scrivendo da solo il motivo quando decide di agire.
- 🔎 L'agente può consultare casi simili prima di decidere, per individuare problemi ricorrenti.
- 🗄️ **PostgreSQL** in produzione (migrato da SQLite affinché la cronologia sopravviva ai redeploy).
- 🐳 **Containerizzato** — API + Postgres via `docker-compose`, un solo comando per l'esecuzione locale.
- ☁️ Distribuito su **Render**, infrastruttura come codice via `render.yaml`.

🔗 **Documentazione API live:** [missao-ia-global-classificador.onrender.com/docs](https://missao-ia-global-classificador.onrender.com/docs)
