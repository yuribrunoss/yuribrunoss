## 🚀 Projeto em destaque — Classificador de Feedbacks com IA

Uma API em produção que classifica feedbacks de clientes e decide por
conta própria quando um caso precisa de um humano.

- 🧠 Classifica o sentimento (positivo / negativo / neutro) com justificativa, usando a **API do Gemini**.
- ✍️ Sugere uma resposta pronta pra enviar ao cliente.
- 🤖 Um **agente de IA** de verdade — não uma regra fixa tipo `if` — decide via **function calling** se um caso precisa de atenção humana, escrevendo o próprio motivo quando decide agir.
- 🔎 O agente pode consultar casos parecidos antes de decidir, pra identificar problemas recorrentes.
- 🗄️ **PostgreSQL** em produção (migrado do SQLite pra que o histórico sobreviva a redeploys).
- 🐳 **Containerizado** — API + Postgres via `docker-compose`, um comando só pra rodar localmente.
- ☁️ Publicado no **Render**, infraestrutura como código via `render.yaml`.

🔗 **Docs da API em produção:** [missao-ia-global-classificador.onrender.com/docs](https://missao-ia-global-classificador.onrender.com/docs)
