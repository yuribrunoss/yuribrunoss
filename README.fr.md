## 🚀 Projet phare — Classificateur de retours clients par IA

Une API en production qui classe les retours clients et décide
elle-même quand un cas nécessite une intervention humaine.

- 🧠 Classe le sentiment (positif / négatif / neutre) avec justification, via l'**API Gemini**.
- ✍️ Suggère une réponse prête à envoyer au client.
- 🤖 Un véritable **agent IA** — pas une règle fixe du type `if` — décide via **function calling** si un cas nécessite un suivi humain, en rédigeant lui-même sa raison quand il décide d'agir.
- 🔎 L'agent peut consulter des cas similaires avant de décider, pour repérer les problèmes récurrents.
- 🗄️ **PostgreSQL** en production (migré depuis SQLite pour que l'historique survive aux redéploiements).
- 🐳 **Conteneurisé** — API + Postgres via `docker-compose`, une seule commande pour l'exécuter localement.
- ☁️ Déployé sur **Render**, infrastructure as code via `render.yaml`.

🔗 **Documentation de l'API en ligne :** [missao-ia-global-classificador.onrender.com/docs](https://missao-ia-global-classificador.onrender.com/docs)
📂 **Code :** [github.com/yuribrunoss/missao-ia-global](https://github.com/yuribrunoss/missao-ia-global)
